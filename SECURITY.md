# Security policy

PyTraT is security software. Please report vulnerabilities privately through GitHub Security
Advisories ("Report a vulnerability" on the repository's Security tab) rather than in public issues.

Include the affected package and version, a description of the impact, and reproduction steps.
We aim to acknowledge reports within three working days.

## Supported versions

Only the latest minor release receives security fixes while the project is pre-1.0.

## Scope

See [docs/threat-model.md](docs/threat-model.md) for what PyTraT defends against and what it
assumes. Reports showing that any *Tested in* mitigation can be bypassed are always in scope.
